# Hotel Booking Cancellation Analysis

## Project Overview

This project analyzes hotel booking data using Microsoft Excel to understand booking patterns and cancellation trends.

## Tool Used

* Microsoft Excel

## Analysis Performed

* Analyzed hotel booking records
* Studied booking and cancellation patterns
* Compared booking status
* Used Excel formulas and data analysis techniques
* Created summaries to understand cancellation trends

## Key Metrics

The project includes analysis of booking and cancellation-related metrics from the provided dataset.

## Project File

* `Hotel_Booking_Cancellation.xlsx` – Excel file containing the dataset and analysis

## Learning Outcome

This project helped me practice data cleaning, Excel formulas, filtering, sorting, and analyzing business data to identify useful trends and insights.
